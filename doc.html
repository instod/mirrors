欢迎使用镜像站

按您的身份选择左侧章节：超算平台用户优先直读公共目录；其他用户通过 HTTPS 浏览与下载。

组学数据库

NCBI、NCBI Open Data（SRA / BLAST DB / PMC OA）、Ensembl、UniProt、PDB 等

系统与应用源

OS 镜像、Conda / Pip 等软件源

高速直连

所内高速访问；所外取决于您的网络环境

合规可用

仅供科研教学，请合理使用

如何选择章节？

研究所超算平台用户请看「HPC 用户」；通过所内网或经授权远程访问的用户请看「普通用户」。

合理使用政策

本镜像站资源仅供科研、教学及个人学习使用，请勿用于商业目的。请避免使用多线程下载工具并发下载，以免对服务器造成过大压力。

禁止滥用与攻击行为

禁止对站点或共享存储进行大规模扫描、未授权爬取与攻击行为；禁止传播违法违规内容。违规访问将被限制并按规定处理。

三步上手

无论您是哪种用户，整体流程都可以归纳为以下三步。

1确认您的身份与访问路径

HPC 用户优先直连公共目录；其他用户通过 HTTPS 下载：

shell # HPC 用户（推荐） cd /hpcfs/fpublic/database/ # 只读公共目录，无需下载 # 网页 / HTTPS 用户 wget -c "https://mirrors.tibhpc.net/<path>" # HTTPS 断点续传

2找到您需要的资源

两种方式都可以：

  • 在首页的「数据库镜像源 / 系统与应用源」表格里直接定位
  • 命令行用 find 或 ls 在公共目录里查找
shell ls /hpcfs/fpublic/database/ # 列出镜像源目录 find /hpcfs/fpublic/database/ncbi -name "*.fna" | head # 在单个源内查找

3取用数据

  • HPC 用户：直接在公共目录中分析，或 cp 到个人目录
  • 网页用户：使用 wget -c 经 HTTPS 下载到本地，支持断点续传

公共目录结构

数据库镜像位于只读公共目录。完整清单以首页为准；超算环境中可用 ls 查看本地挂载路径。

tree /hpcfs/fpublic/database # 只读 ├── ncbi/ … # FTP 全站 ├── ncbi-opendata/ … # AWS：SRA / BLAST DB / PMC OA ├── ensembl/ … ├── uniprot/ … ├── pdb-redo/ … └── … # 更多条目见首页
目录会随同步更新

请以首页列表或 ls /hpcfs/fpublic/database 的实时结果为准，勿依赖本文示例穷举。

直访公共目录（HPC 用户）

最推荐的方式——不占用个人存储，数据始终保持最新。

1进入公共目录

shell cd /hpcfs/fpublic/database ls # 查看所有可用镜像源 cd ncbi # 进入 NCBI 数据目录

2查看目录占用

统计某个镜像源占用空间：

shell du -sh /hpcfs/fpublic/database/ncbi # 仅查单个子目录
请勿对整库盲目 du

对超大目录做 du / 全树 find 会长时间占用共享存储 IO。容量信息优先看首页表格；确需统计时请限定到具体子目录。

推荐做法

直接在公共目录跑分析（用 --input 等参数指向公共路径），可显著节省个人家目录的存储配额和 IO 等待时间。

搜索与定位（HPC 用户）

目录层级较深时，命令行工具可以快速定位文件。

1按文件名查找

shell find /hpcfs/fpublic/database/ncbi -name "*.fna" | head # 在 ncbi 下找序列 find /hpcfs/fpublic/database/ncbi -iname "*pdb*" | head # 限定子目录查找 find /hpcfs/fpublic/database/kegg -maxdepth 2 -type f | wc -l # 浅层统计

2按文件大小查找

shell find /hpcfs/fpublic/database/ncbi -type f -size +1G | head # 限定到单个源 find /hpcfs/fpublic/database/ncbi -type f -size +100M -size -1G | head

3按修改时间查找

shell find /hpcfs/fpublic/database/ncbi -type f -mtime -7 | head # 近 7 天更新

4搜索建议

优先用 find 限定路径与文件名模式；避免对整库做无过滤的全量扫描。

复制到个人目录（HPC 用户）

如果分析脚本必须使用本地路径，或需要长期保留某个快照，可将公共目录的数据复制到个人家目录。

1单文件复制

shell cp /hpcfs/fpublic/database/ncbi/file.txt /hpcfs/fhome/yourname/

2整个目录复制

shell cp -r /hpcfs/fpublic/database/ncbi/ /hpcfs/fhome/yourname/ncbi_copy/
注意存储配额

请勿整库复制超大镜像到家目录。优先在作业中直接引用公共路径；确需副本时只拷贝所需子集。

Slurm 作业访问（HPC 用户）

在超算平台上，所有数据访问都应该通过作业调度系统，避免在登录节点执行重活。

1提交批处理作业

编写一个简单的作业脚本 run.sh：

bash #!/bin/bash #SBATCH --job-name=myrun #SBATCH --partition=cpu #SBATCH --nodes=1 #SBATCH --ntasks=1 #SBATCH --cpus-per-task=8 #SBATCH --mem=32G #SBATCH --time=24:00:00 #SBATCH --output=myrun_%j.log cd /hpcfs/fhome/$USER/work ./my_pipeline --input=/hpcfs/fpublic/database/ncbi/genomes --output=./results

提交作业：

shell sbatch run.sh squeue -u $USER # 查看作业状态 sacct -j <JOBID> --format=JobID,State,Elapsed,MaxRSS # 历史资源使用

2交互式调试

需要交互式 shell 时申请计算节点：

shell salloc --partition=cpu --cpus-per-task=4 --mem=16G --time=02:00:00 srun --pty bash # 在分配到的节点上打开 bash

3常用 Slurm 命令

命令作用
sinfo查看分区与节点状态
squeue查看排队/运行中作业
sbatch <script>提交批处理作业
scancel <jobid>取消作业
sacct查看历史作业与资源
scontrol show job <id>查看作业详细信息

网页下载（普通用户）

最简单的取用方式——直接通过浏览器打开首页，进入对应数据源页面下载。

  1. 访问 镜像站首页
  2. 在「数据库镜像源」或「系统与应用源」列表中找到目标
  3. 点击数据源名称即可在浏览器中浏览/下载
适用场景

下载单个小文件（< 1GB）或临时取用。下载大文件建议改用命令行工具 wget -c，避免浏览器断开。

wget / curl（普通用户）

最常用的命令行下载方式，支持断点续传、限速、批量等高级功能。

1基础用法

shell wget -c "https://mirrors.tibhpc.net/<镜像路径>" -O outfile # wget 断点续传 curl -L -C - -o outfile "https://mirrors.tibhpc.net/<镜像路径>" # curl 等价写法

2wget 常用参数

参数作用
-c / --continue断点续传，恢复中断的下载
-O FILE指定下载后的文件名
-P DIR指定文件下载到的目录
-b后台运行下载进程
-q静默模式（不输出进度）
-t N重试次数（0 = 无限）
--limit-rate=100k限速 100KB/s
-i list.txt从文件读取 URL 列表批量下载

3批量下载

把 URL 列表写入文件 urls.txt，一行一个：

shell wget -c -i urls.txt

性能与建议

遵循以下原则可以让您用得更舒心，也减少对镜像站的不必要压力。

1选择合适的并发

  • 单文件下载：wget -c 单连接即可，多连接对 HTTP 镜像收益有限
  • 批量下载：建议 ≤ 4 路并发，避免触发站点限速

2HPC 用户优先

如果您的使用场景是"读多写少"，请直接访问 /hpcfs/fpublic/database，避免下载冗余副本。

常见问题 FAQ

点击展开答案。

本站的下载速度如何？

所内用户：通常可获得较好的下载/直读体验。

远程用户：速度取决于您的接入网络，请避免过高并发。

下载文件的 MD5/SHA256 不符怎么办？

如果数据源当前处于"正在同步"状态，部分文件校验值临时不匹配是正常现象。请稍后再试，或在首页表格中查看该数据源的同步状态。

若长期校验失败，请通过研究所内部支持渠道反馈，并附上数据源名称与文件路径。

下载提示权限不足或获取数据为 0？

请先确认已接入研究所内网（或经授权的远程访问方式）。

若仍提示权限不足，请通过内部支持渠道联系运维协助核查。

镜像的数据是何时同步的？

各镜像按计划定期从上游更新。首页表格中的「上次同步时间」以相对时间展示（如「3 小时前」「2 天前」），鼠标悬停可查看精确时间戳；「下次同步」同样为相对时间（如「5 小时后」）。

若显示「暂无计划」，表示该源尚未启用定时同步。具体状态以首页表格为准。

数据能不能用商业用途？

不可以。本镜像站资源仅供科研、教学及个人学习使用，请遵守上游数据库的许可证条款。

想申请新增镜像源怎么办？

请通过研究所内部支持渠道提出申请，说明数据源名称、公开上游地址、预估体量与用途。是否纳入由运维评估后决定。
